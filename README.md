## 📌 About the Project

**Project Fundamental Booster** is a hands-on Microsoft Excel project created to practise and understand important Excel formulas and functions using three different types of datasets.

The workbook brings together academic records, employee information and sales transactions. It demonstrates how formulas can automate calculations, apply conditions, retrieve information, work with dates and text, and summarize data.

## 📁 Workbook Overview

| Worksheet | Purpose |
|---|---|
| `Student_Grade` | Student marks, percentages, grades and pass/fail results |
| `Employees_data` | Employee details, salary, joining dates and service duration |
| `Sales_dat` | Sales transactions, discounts, date details and product prices |

---

## 🎓 1. Student Grade Analysis

This worksheet contains student IDs, names, subject marks and enrollment dates. Formulas are used to calculate academic results and retrieve student information.

**What this sheet covers**
- Calculate total marks and percentage.
- Assign grades using nested conditions.
- Identify Pass or Fail results.
- Check whether both or either of two subject marks are above 80.
- Retrieve student details using Student ID.
- Filter students according to marks or other conditions.

**Excel functions practised**

`SUM` · `IF` · `AND` · `OR` · `XLOOKUP` · `VLOOKUP` · `FILTER` · `COUNTIF` · `COUNTIFS` · `MAX` · `AVERAGEIF`

## 👥 2. Employee Data Analysis

This worksheet contains employee IDs, names, departments, salaries and joining dates. It focuses on employee service calculations and department-wise salary analysis.

**What this sheet covers**
- Calculate completed years of service.
- Calculate the number of days since joining.
- Display the joining month.
- Retrieve employee salary and department details.
- Calculate total salary department-wise.
- Count employees meeting department and salary conditions.
- Demonstrate dynamic cell references.

**Excel functions practised**

`DATEDIF` · `TODAY` · `IFERROR` · `ABS` · `TEXT` · `XLOOKUP` · `SUMIF` · `COUNTIFS` · `OFFSET` · `INDIRECT`

## 🛒 3. Sales Data Analysis

This worksheet contains sales IDs, products, regions, salespersons, transaction amounts and dates. It also includes a product price table and formula-based discount calculations.

**What this sheet covers**
- Extract month and day from transaction dates.
- Apply discounts based on sales amount.
- Calculate discount amounts.
- Round values up, down or to the nearest whole number.
- Find minimum amounts for products.
- Retrieve product information using lookup formulas.
- Calculate sales totals using multiple criteria.

**Excel functions practised**

`TEXT` · `IF` · `ROUND` · `CEILING` · `FLOOR` · `SUMIFS` · `MINIFS` · `VLOOKUP` · `XLOOKUP` · `INDEX` · `MATCH` · `XMATCH` · `LEFT` · `UPPER` · `LOWER` · `OFFSET` · `INDIRECT`

## 🧠 Key Excel Concepts

| Concept | Application |
|---|---|
| Logical Functions | Apply conditions and make decisions |
| Lookup Functions | Search and retrieve matching information |
| Date Functions | Calculate service periods and format dates |
| Text Functions | Extract and change text formats |
| Mathematical Functions | Calculate totals, discounts and rounded values |
| Conditional Functions | Summarize records based on given criteria |
| Dynamic References | Refer to cells and ranges dynamically |

- **Excel Tables** – structured data references

## 🚀 How to Use This Workbook

1. Download `Project_Fundamental_Booster.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Explore the three worksheets: `Student_Grade`, `Employees_data` and `Sales_dat`.
4. Select formula cells to view the formulas in the formula bar.
5. Change sample input values and observe how the calculated results update.
6. Practise the functions by applying them to other rows or sample data.

> **Compatibility:** Some formulas, including `XLOOKUP`, `FILTER`, `XMATCH` and `MINIFS`, require a supported version of Microsoft Excel. Older versions may not support every function used in this workbook.
